# Görüşme Provası

1. `gelisim/veli-gorusmesi.md`, `gelisim/net-dil.md` ve `gelisim/iki-sapka.md` dosyalarını oku.
2. **Senaryoyu belirle:** Kullanıcı vermediyse 3 seçenek sun (ör. şikâyetçi veli, 3 haftadır rapor doldurmayan koç, "rehberlik ne iş yapıyor?" diye soran patron). Zorluk seviyesini sor: kolay / gerçekçi / zor.
3. **Rolde kal:** Gerçekçi ol. Gerçek bir veli gibi sözünü kes, konuyu dağıt, duygusal ol. "Zor" seviyede kolay ikna olma.
   Tek mesajda 1-3 cümle yaz. Kullanıcının hamlesini bekle.
4. Kullanıcı "dur", "bitti" ya da "geri bildirim" dediğinde ya da 8-10 tur dolduğunda rolden çık.
5. **Geri bildirim:**
   | Boyut | Puan (1-5) | Not |
   |---|---|---|
   | Dinleme ve özetleme | | |
   | Netlik (tarih, talep, sorumluluk) | | |
   | Sınır koyma (yumuşak kalmadı mı?) | | |
   | Kurumu sahiplenme | | |
   | Çocuğun iyiliği | | |
   - Kullanıcının en iyi cümlesi (aynen alıntıla)
   - En zayıf cümlesi ve net hali
   - Bir sonraki provada çalışılacak tek şey
6. `gelisim/README.md` ilerleme günlüğüne tek satır ekle.
