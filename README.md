# Odak Eğitim · Rehberlik ve Sosyal Medya Çalışma Sistemi

Claude Code ile kullanılan çalışma sistemi. Koçluk raporlarını denetler, riskli öğrencileri öne çıkarır,
veliye giden mesajları hazırlar ve Instagram postlarını düzenli olarak hazırlayıp denetler.

- `CLAUDE.md`: Claude'un nasıl düşüneceği, denetçi modu, kesin kurallar
- `marka/`: marka dili (taslak) + öğrenme günlüğü (düzeltmelerden öğrenilen kurallar)
- `denetim/`: post ve koçluk raporu denetim listeleri
- `kocluk/`: risk öncelik kuralları, koç hatırlatma ve veli mesajı şablonları
- `sosyal-medya/`: post şablonu, özel günler takvimi, haftalık planlar
- `.claude/skills/`: `/haftalik-post` `/post-denetle` `/kocluk-denetimi` `/veli-ozeti` `/ogren`

> ⚠️ Öğrenci ve veli verisi bu repoya konmaz. Veriler Google Drive'da kalır.
