# Post Şablonu

Her post bu yapıyla hazırlanır ve `sosyal-medya/haftalar/<YYYY-AA-GG>_hafta.md` içine yazılır
(dosya adındaki tarih haftanın Pazartesi günüdür).

```markdown
### <Gün> <Tarih> · <Sütun> · <Format: Tekil / Carousel N kart / Reels / Story>
**Yayın saati:** HH:MM
**Kitle:** veli | öğrenci (<kademe>) | ikisi
**Amaç:** kaydedilme | paylaşılma | güven | duyuru

**Kapak (≤7 kelime):** ...

**Kartlar / Sahne akışı:**
1. ...
2. ...

**Caption:**
<ilk satır kanca: ilk 125 karakterde ana fikir>
<gövde>
<tek CTA>

**Hashtag:** #OdakEğitim ...
**Görsel brief (tasarımcıya):** renk, görsel, yasaklar
**Doğrulanan bilgiler:** <tarih/sayı ve kaynağı>

**DENETİM**
| # | Kontrol | Sonuç |
|---|---|---|
| 1 | Mahremiyet | |
| ... | ... | |

DENETİM: ✅ / ⚠️ / ⛔
Denetçi itirazı: ...
```

## Saat önerileri (başlangıç varsayımı, Instagram istatistiklerine göre güncellenecek)
- Veli içeriği: 20:30-21:30
- Öğrenci içeriği: 17:30-18:30 (okul çıkışı) ya da hafta sonu 11:00
- Duyuru: 08:00-09:00
